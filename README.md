# WebScope

Website intelligence platform — analyze any URL for performance, SEO, accessibility, content, branding, and security.

## Status

Work in progress. Currently in Fase 1 (project setup + first analyzers).

## Stack

- [Astro](https://astro.build) — static site framework
- [TypeScript](https://www.typescriptlang.org) — type safety
- [Apache ECharts](https://echarts.apache.org) — charts and visualizations
- [Zod](https://zod.dev) — schema validation
- [Cloudflare Pages](https://pages.cloudflare.com) — hosting
- [Cloudflare Workers](https://workers.cloudflare.com) — proxy API
- [Supabase](https://supabase.com) — auth + database
- [Claude Haiku](https://anthropic.com) — AI suggestions

## Development

```bash
npm install
npm run dev
```
